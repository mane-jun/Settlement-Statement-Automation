# 정산내역서 자동화

주문 엑셀 파일을 정산내역서 맨 아래에 규칙대로 이어붙이고, 보관박스(포장가방) 금액을 자동으로 계산해 넣는 윈도우용 도구입니다.

설치할 프로그램은 없습니다. **폴더를 내려받아 `정산내역서 자동화.bat` 을 쓰면 끝입니다.**

---

## 하는 일

1. 주문 엑셀 파일(또는 폴더 통째로)을 정산내역서 맨 아래에 이어붙이기
2. 주문일을 A열에 세로 병합하고, 바로 윗 행의 서식을 그대로 물려받기
3. 보관박스 표시를 사이즈·수량에 따라 **금액으로 환산**해서 넣기
4. 이미 글자로 남아 있는 `포장가방` 표시도 금액으로 바꾸기
5. 실행 직전 상태를 `백업` 폴더에 자동 저장

이미 들어가 있는 주문일은 자동으로 건너뛰므로, 같은 파일을 두 번 올려도 중복되지 않습니다.

---

## 준비물

| 항목 | 필요 조건 |
|---|---|
| 운영체제 | **윈도우** (맥·리눅스 불가) |
| 엑셀 | **PC에 설치된 데스크탑용 엑셀** (Office 2016 이상 또는 M365 설치판) |

> 웹 엑셀(Excel Online)·한셀·리브레오피스로는 동작하지 않습니다.
> 엑셀 COM 자동화를 쓰기 때문에 설치판 엑셀이 반드시 필요합니다.

---

## 설치

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP`, 또는 `git clone`)
2. **ZIP 으로 받았다면** 압축을 풀기 전에 ZIP 파일 우클릭 → 속성 → 아래쪽 **`차단 해제`** 체크 → 확인.
   (이걸 안 하면 엑셀이 제한된 보기로 열어서 저장에 실패할 수 있습니다)
3. 압축을 푼 폴더에 **본인의 정산내역서 `.xlsx` 파일을 같이 넣어둡니다.**
   같은 폴더에 두면 프로그램이 알아서 찾습니다. 다른 곳에 둬도 메뉴 `5번` 으로 지정할 수 있습니다.

---

## 쓰는 법

### 방법 A — 끌어다 놓기 (가장 빠름)

주문 엑셀 파일이나 그 파일들이 든 폴더를 **`정산내역서 자동화.bat` 아이콘 위로 끌어다 놓으면** 바로 처리됩니다.

### 방법 B — 더블클릭해서 메뉴 고르기

```
--------------------------------------------
  1. 주문 파일 추가하기
  2. 주문 파일 추가하기 (중복 무시)
  3. 보관박스 금액 다시 계산하기
  4. 금액 설정 바꾸기
  5. 정산내역서 파일 바꾸기
  0. 끝내기
--------------------------------------------
```

> 정산내역서가 **엑셀에서 열려 있으면 저장할 수 없습니다.** 닫고 실행해주세요.

자세한 규칙은 **[사용법.md](사용법.md)** 를 보세요.

## 보관박스 금액 규칙

주문 파일에 **보관박스 표시가 있는 행만** 금액이 들어갑니다.

| 사이즈 | 단가 |
|---|---|
| 가로·세로가 **둘 다 254 미만** | 3,850원 |
| 가로·세로 중 **하나라도 254 이상** | 4,400원 |

여기에 수량을 곱한 값이 L열에 들어갑니다. (예: `305x305` 수량 2 → 8,800원)

금액과 기준은 메뉴 `4번` 또는 [`보관박스_금액설정.txt`](보관박스_금액설정.txt) 에서 숫자만 고치면 됩니다.

---

## 정산내역서 양식

이 프로그램은 아래 양식을 전제로 합니다. 양식이 다르면 열 번호를 맞춰야 합니다.

- 데이터는 **3행부터** 시작
- **A~M열** 구성: 주문일 · 구분 · 품목 · 수령자 · 사이즈 · 단가 · 수량 · 공급가액 · VAT · 택배비 · 합계 · 보관박스 · 비고
- 시트 이름에 `26년 8월` 처럼 **연·월이 들어간 첫 시트**를 사용

주문 파일에는 `주문일` · `품목` · `사이즈` 머리글이 있어야 합니다. (`수령인` · `수량` · `보관박스` 는 있으면 함께 옮깁니다)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `정산내역서 자동화.bat` | **이것만 실행하면 됩니다** |

| `백업/` | 되돌릴 수 있는 자동 백업 (실행하면 자동 생성) |

## 주의

- **`settlement.ps1` 을 메모장으로 열어 저장하지 마세요.**
  이 파일은 UTF-8 BOM 으로 저장돼 있는데 윈도우 메모장은 BOM 없이 저장합니다. 그러면 한글이 전부 깨집니다.
  금액을 바꿀 때는 메뉴 `4번` 을 쓰세요. (설정 파일은 메모장으로 고쳐도 안전합니다)
- **실제 정산내역서와 주문 파일(`.xlsx`)은 이 저장소에 올라가 있지 않습니다.**
  수령인 이름 같은 개인정보가 들어 있어 `.gitignore` 로 제외했습니다. 본인 파일을 직접 넣어 쓰세요.
