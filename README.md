# 정산내역서 자동화

주문 엑셀 파일을 정산내역서 맨 아래에 규칙대로 이어붙이고, **단가·공급가액·VAT·택배비·합계·보관박스를 자동으로 채워 넣는** 윈도우용 도구입니다.

설치할 프로그램은 없습니다. **폴더를 내려받아 `정산내역서 자동화.bat` 을 쓰면 끝입니다.**

---

## 하는 일

1. 주문 엑셀 파일(또는 폴더 통째로)을 정산내역서 맨 아래에 이어붙이기
2. 주문일을 B열에 세로 병합하고, 바로 윗 행의 서식을 그대로 물려받기
3. **단가**를 품목·사이즈로 조회해서 넣기
4. **공급가액·VAT·합계**를 수식으로 넣기 (`=G*H`, `=I*0.1`, `=I+J+K+M`)
5. **택배비**를 사이즈·배송조건에 따라 계산해서 넣기
6. **보관박스** 표시를 사이즈·수량에 따라 금액으로 환산해서 넣기
7. 실행 직전 상태를 `백업` 폴더에 자동 저장

이미 들어가 있는 주문일은 자동으로 건너뛰므로, 같은 파일을 두 번 올려도 중복되지 않습니다.

계산 규칙은 26년 1~7월 정산내역서 **738행을 역산해서** 뽑아냈습니다. 공급가액·VAT·합계는 738행 전부와 일치하고, 택배비는 99.1%, 보관박스는 97.5% 일치합니다.

## 준비물

| 항목 | 필요 조건 |
|---|---|
| 운영체제 | **윈도우** (맥·리눅스 불가) |
| 엑셀 | **PC에 설치된 데스크탑용 엑셀** (Office 2016 이상 또는 M365 설치판) |

> 웹 엑셀(Excel Online)·한셀·리브레오피스로는 동작하지 않습니다.
> 엑셀 COM 자동화를 쓰기 때문에 설치판 엑셀이 반드시 필요합니다.

## 설치

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP`, 또는 `git clone`)
2. **ZIP 으로 받았다면** 압축을 풀기 전에 ZIP 파일 우클릭 → 속성 → 아래쪽 **`차단 해제`** 체크 → 확인.
   (이걸 안 하면 엑셀이 제한된 보기로 열어서 저장에 실패할 수 있습니다)
3. 압축을 푼 폴더에 **본인의 정산내역서 `.xlsx` 파일을 같이 넣어둡니다.**
   같은 폴더에 두면 프로그램이 알아서 찾습니다. 다른 곳에 둬도 메뉴 `7번` 으로 지정할 수 있습니다.

## 쓰는 법

### 방법 A — 끌어다 놓기 (가장 빠름)

주문 엑셀 파일이나 그 파일들이 든 폴더를 **`정산내역서 자동화.bat` 아이콘 위로 끌어다 놓으면** 바로 처리됩니다.

### 방법 B — 더블클릭해서 메뉴 고르기

```
--------------------------------------------
  1. 주문 파일 추가하기
  2. 주문 파일 추가하기 (중복 무시)
  3. 보관박스 금액 다시 계산하기
  4. 보관박스 금액 설정 바꾸기
  5. 단가표 고치기
  6. 택배비 설정 바꾸기
  7. 정산내역서 파일 바꾸기
  0. 끝내기
--------------------------------------------
```

> 정산내역서가 **엑셀에서 열려 있으면 저장할 수 없습니다.** 닫고 실행해주세요.

자세한 규칙은 **[사용법.md](사용법.md)** 를 보세요.

## 계산 규칙

### 단가

품목과 사이즈로 [`단가표.txt`](단가표.txt) 를 찾아 넣습니다. 66개 규격이 들어 있습니다.

- **품목은 6가지로 묶어서** 알아봅니다 — 아크릴 / 캔버스 / 알루미늄 / 원목클래식 / 호두나무 / 종이포스터.
  `알루미늄골드(아크릴판)`, `알루미늄 화이트 프레임` 처럼 적혀 있어도 모두 **알루미늄** 한 줄로 봅니다.
  (골드·화이트·블랙·실버는 값이 같습니다)
- 가로세로 순서, 대소문자, 구분자(`x X * _ 공백`)는 알아서 맞춥니다. `A2`~`A5` 규격도 인식합니다.
- **±5mm 오차는 같은 규격으로 봅니다.** (`202`와 `203`, `304`와 `305`)
- **캔버스만 두께가 값을 바꿉니다.** `305x406x30` 13,200원 / `305x406x45` 14,500원.
- 네 번째 칸에 **적용시작일**을 적으면 날짜별로 단가를 나눌 수 있습니다.

> 표에 없는 사이즈는 **단가를 비우고 비고에 `단가확인` 을 남깁니다.**
> 틀린 금액이 조용히 들어가는 것보다 눈에 띄게 비워 두는 쪽이 안전합니다.

### 택배비

**긴변 + 짧은변의 합**으로 정합니다. 면적이나 긴 변 하나만 보는 게 아닙니다.

| 긴변+짧은변 | 택배비 |
|---|---|
| ≤ 700 | 3,000원 |
| 701 ~ 900 | 3,500원 |
| 901 ~ 1,100 | 4,000원 |
| 1,101 ~ 1,300 | 5,000원 |
| 1,300 초과 | 6,000원 |

- **수령인이 비어 있는 줄 → 0원** (윗줄과 같은 배송이므로)
- 배송메모에 `방문`·`퀵` → 0원 · 주소가 제주 → **+3,000원**
- 종이포스터 → 한 단계 아래 금액
- **수량 2개 이상은 비워 둡니다.** 상자 수가 그때그때 달라 규칙이 서지 않았습니다.
  비고에 `택배비확인` 이 남습니다.

구간·금액은 [`택배비설정.txt`](택배비설정.txt) 에서 바꿉니다.

### 보관박스

주문 파일에 **보관박스 표시가 있는 행만** 금액이 들어갑니다.
금액은 **짧은 변**으로 정합니다. **긴 변이 아닙니다.**

| 짧은 변 | 금액 |
|---|---|
| 254 미만 | 3,850원 |
| 254 이상 355 미만 | 4,400원 |
| 355 이상 | 7,700원 |

여기에 수량을 곱한 값이 M열에 들어갑니다. (예: `406x406` 수량 2 → 15,400원)

> 세 금액 모두 **부가세 포함가**입니다 (3,500·4,000·7,000 + 10%).
> 그래서 합계 수식에서 VAT를 다시 곱하지 않고 그대로 더합니다.

금액·기준은 메뉴 `4번` 또는 [`보관박스_금액설정.txt`](보관박스_금액설정.txt) 에서 숫자만 고치면 됩니다.

## 정산내역서 양식

이 프로그램은 아래 양식을 전제로 합니다. 양식이 다르면 열 번호를 맞춰야 합니다.

- 데이터는 **3행부터** 시작 (2행이 머리글)
- 표는 **B열에서 시작합니다.** A열은 비워 둡니다.
- **B~N열** 구성: 주문일 · 구분 · 품목 · 수령자 · 사이즈 · 단가 · 수량 · 공급가액 · VAT · 택배비 · 합계 · 보관박스 · 비고
- 시트 이름에 `26년 8월` 처럼 **연·월이 들어간 첫 시트**를 사용

| 열 | 항목 | 채우는 방법 |
|---|---|---|
| B | 주문일 | 주문 파일에서 (세로 병합) |
| C | 구분 | 비움 |
| D~F | 품목 · 수령자 · 사이즈 | 주문 파일에서 |
| **G** | **단가** | 단가표 조회 |
| H | 수량 | 주문 파일에서 |
| **I** | **공급가액** | 수식 `=G*H` |
| **J** | **VAT** | 수식 `=I*0.1` |
| **K** | **택배비** | 규칙 계산 |
| **L** | **합계** | 수식 `=I+J+K+M` |
| **M** | **보관박스** | 금액 환산 |
| **N** | **비고** | `단가확인`·`택배비확인`·`제주` 표시 |

> **I·J·L 은 값이 아니라 수식으로 들어갑니다.** 나중에 단가나 택배비를 손으로 고치면
> 공급가액·VAT·합계가 저절로 따라옵니다.

주문 파일에는 `주문일` · `품목` · `사이즈` 머리글이 있어야 합니다.
(`수령인` · `수량` · `보관박스` 는 있으면 함께 옮기고, `주소` · `배송메모` 는 택배비를 정할 때 읽습니다)

## 주의

- **`settlement.ps1` 을 메모장으로 열어 저장하지 마세요.**
  이 파일은 UTF-8 BOM 으로 저장돼 있는데 윈도우 메모장은 BOM 없이 저장합니다. 그러면 한글이 전부 깨집니다.
  금액을 바꿀 때는 메뉴 `4`~`6번` 을 쓰세요. (설정 파일은 메모장으로 고쳐도 안전합니다)
- **보관박스 기준이 바뀌었습니다.** 예전에는 *긴 변* 254 이상이면 4,400원이었지만,
  실제 1~7월 데이터에서 `203x305` 는 긴 변이 305인데도 83건 전부 3,850원이었습니다.
  지금은 **짧은 변** 기준 3단계입니다. 옛 형식 설정 파일은 실행할 때 자동으로 새 형식으로 바뀝니다.
- **실제 정산내역서와 주문 파일(`.xlsx`)은 이 저장소에 올라가 있지 않습니다.**
  수령인 이름·연락처·주소 같은 개인정보가 들어 있어 `.gitignore` 로 제외했습니다. 본인 파일을 직접 넣어 쓰세요.
