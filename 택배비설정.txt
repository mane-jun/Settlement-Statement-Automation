# ============================================================
#  택배비 설정
# ============================================================
#  택배비는 사이즈의 "긴변 + 짧은변" 합으로 정해집니다.
#  (면적이나 긴 변 하나만 보는 게 아닙니다)
#
#  구간 = 합계상한 : 금액   -> 그 값 이하면 그 금액
#  아래 순서대로 위에서부터 맞는 첫 구간을 씁니다.
# ============================================================

구간 = 700 : 3000
구간 = 900 : 3500

구간 = 99999 : 6000

#  덧붙는 규칙
# ------------------------------------------------------------
#  수령인이 비어 있는 줄은 바로 윗줄과 같은 배송이라 0원입니다.
#  종이포스터는 구간표에서 한 단계 아래 금액을 씁니다.
#
#  방문수령/퀵  : 배송메모에 아래 낱말이 있으면 0원
#  제주         : 주소가 제주면 기본 택배비에 더할 금액

방문낱말 = 방문,방문수령,퀵,직접수령
